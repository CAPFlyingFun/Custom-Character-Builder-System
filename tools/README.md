# Tools

- `local-texture-lab.html` -- Joshua's Local Texture Lab (2026-11-19: "save to your Repo for like for hair texture, even body
  texture to get height maps and stuff"): an offline page that turns a picture into tileable PBR maps (base colour,
  height, normal, roughness, AO) or makes one procedurally, and exports them as a zip. Open it in a browser; nothing is
  uploaded. To be used for the hair's depth and detail (his: "add better depth and detail on like the hair so it doesn't
  look so flat").
